# LifeOS 1.1.2

Personal life planner: tasks, habits, fitness and reviews.

This repository contains the prebuilt static PWA only. Personal records stay in each browser IndexedDB, not in this repository. Different devices do not automatically synchronize. Export JSON backups before switching addresses.

## Publish

In repository Settings > Pages, choose Deploy from a branch, then main and /(root), and Save. Open the URL shown by GitHub after deployment completes.

On Android Chrome, open the HTTPS URL, wait for the first load, then use Install app / Add to Home screen. Android device checks are still required. Reminders are only checked while the page can run.
